# 技术栈与运行方式

## 1. 主要技术栈

| 类别 | 技术 / 说明 |
| :--- | :--- |
| 编程语言 | Go 1.25+（以 `go.mod` 为准）、Python 3.10+（部分 YAML 工具依赖） |
| 核心框架 | [Gin](https://github.com/gin-gonic/gin)（HTTP）、[CloudWeGo Eino](https://github.com/cloudwego/eino)（Agent ADK）、[go-sdk MCP](https://github.com/modelcontextprotocol/go-sdk) |
| 前端技术 | 单页 `web/templates/index.html` + `web/static/js/*.js`；无打包器；[i18next](https://www.i18next.com/)（CDN UMD） |
| 后端技术 | 单体进程 `cmd/server`；SSE 流式对话；OpenAPI 由 `internal/handler/openapi.go` 维护 |
| 数据存储 | SQLite（`github.com/mattn/go-sqlite3`），默认 `data/conversations.db`、`data/knowledge.db` |
| 中间件 / 基础设施 | 可选 HTTPS/HTTP2、OpenTelemetry、多机器人 IM 回调（企微/钉钉/飞书等） |

配置以 `config.yaml`（由 `config.example.yaml` 复制）为主，支持 Web 设置页可视化修改与部分热应用。

## 2. 代码组织与仓库形态

- **仓库形态**：单仓
- **逻辑项目根目录**：仓库根目录（与 `go.mod` 同级）
- **治理与规则**：`.design-rules/`、后续 `.design/` 均位于仓库根
- **是否包含多应用 / 多包结构**：是；同一仓库内包含主服务、辅助 `cmd/*`、可选 `plugins/` 与 `mcp-servers/`

| 远程名 | 地址 | 用途 |
| :--- | :--- | :--- |
| `origin` | `https://github.com/tanglixu94/CyberStrikeAI.git` | 内部 fork，**默认 fetch/push** |

## 3. 本地运行方式

### 3.1 环境要求

- Go 1.25+（见 `go.mod`）
- Python 3.10+（`run.sh` 会创建 venv 并安装 `requirements.txt`；部分工具配方依赖 Python 包）

### 3.2 启动入口

**推荐（一键）：**

```bash
chmod +x run.sh && ./run.sh
```

`run.sh` 会检查 Go/Python、安装依赖、编译并启动；默认 **HTTPS** + 项目根 `config.yaml`（可用 `./run.sh --http` 明文 HTTP）。

**开发常用：**

```bash
go run ./cmd/server --config config.yaml
```

**构建：**

```bash
go build -o cyberstrike-ai ./cmd/server
```

### 3.3 关键配置与环境

| 项 | 说明 |
| :--- | :--- |
| 配置文件 | 根目录 `config.yaml`（勿将含密钥的文件提交仓库）；示例见 `config.example.yaml` |
| 数据目录 | `data/`（SQLite、上传、checkpoint 等运行时数据，默认应在 `.gitignore`） |
| Go 代理 | `go.mod` 注释建议：`GOPROXY=https://goproxy.cn,direct` |
| HTTPS | `server.tls_*` 或 `run.sh --https`；生产证书路径见 `config.example.yaml` 注释 |

首次启动会输出 `admin` 初始密码（仅一次），登录后应立即修改。

## 4. 测试与验证方式

| 方式 | 命令 / 入口 |
| :--- | :--- |
| Go 单测（主） | `go test ./internal/...` |
| 指定包 | 如 `go test ./internal/multiagent`、`go test ./internal/handler` |
| 构建冒烟 | `go build -o cyberstrike-ai ./cmd/server` |
| API 手测 | 浏览器 `/api-docs` |
| 文档检查 | `python3 scripts/check-docs.py`（若脚本存在） |
| 前端 | 改 `web/static` 后刷新浏览器；新文案需同步 i18n JSON |

重点测试包（维护高频故障区）：`internal/security`、`internal/mcp`、`internal/multiagent`、`internal/workflow`、`internal/knowledge`、`internal/handler`、`internal/database`。

详见 `docs/zh-CN/testing.md`。

## 5. AI 使用提示

- **修改代码前应优先确认的运行边界**：本地是否有可写 `data/`、模型 API 是否已在设置页配置、改动是否依赖 Python 工具环境
- **不应擅自假设的环境条件**：生产 TLS 证书、内网 GitLab 可达性、C2/WebShell 已按授权环境开启
- **运行方式复杂或涉及发布时**：先查 `docs/zh-CN/deployment.md`、`docs/zh-CN/configuration.md`；生产部署细节见 `发布与部署约束.md`（**部分待后续维护**）
