## 2. 核心业务模块

### 2.1 对话与 Agent

- **职责**：流式对话、工具循环、多 Agent 编排、检查点恢复
- **上下游**：Handler（SSE）← multiagent → mcp / knowledge / database
- **常见变更**：新中间件、流式事件、模型兼容、HITL 分支

关键 Handler：`agent.go`、`eino_single_agent.go`、`multi_agent.go`

### 2.2 MCP 与工具

- **职责**：工具 schema、执行、worker 弹性等待、外部 MCP 联邦
- **上下游**：Agent 调用；monitor 记录；security/hitl 约束
- **常见变更**：新 YAML 工具、内置 Go 工具、执行治理

### 2.3 工作流

- **职责**：可视化工作流图的运行时
- **上下游**：`handler/workflow*.go`、database 持久化
- **常见变更**：新节点类型、运行状态 API

### 2.4 知识库

- **职责**：文档导入、embedding、检索、rerank
- **上下游**：独立 DB；向 Agent 暴露检索工具
- **常见变更**：分块策略、索引迁移、检索链

### 2.5 安全运营（资产 / 漏洞 / 批量任务 / 项目攻击链）

- **职责**：资产管理、漏洞生命周期、批量任务队列、跨会话项目事实
- **上下游**：database + 专用 handler（`asset.go`、`vulnerability*.go`、`project.go` 等）
- **常见变更**：筛选、导入导出、图谱视图

### 2.6 WebShell / C2 / Terminal

- **职责**：授权环境下的受控远程操作
- **上下游**：MCP 工具、WebSocket、审计
- **常见变更**：编码、会话管理、审批策略

> 默认视为**高风险**；改动必须对照 `docs/zh-CN/security-model.md` 与 HITL 配置。

## 3. 公共能力模块

| 模块 | 适用范围 | 推荐复用场景 | 使用限制 |
| :--- | :--- | :--- | :--- |
| `internal/database` | 所有持久化 | 新表、查询、迁移 | 必须幂等迁移、兼容旧库 |
| `internal/handler/openapi.go` | 公开 API | 新 REST 接口 | 与实现同步 |
| `internal/audit` | 管理类写操作 | 配置、用户、删除 | 不记录对话正文 |
| `internal/monitor` | 工具与长任务 | 可取消执行 | 保留策略见配置 |
| `internal/hitl` | MCP 工具调用 | 高风险审批 | 勿默认全开白名单 |
| `web/static/js` 公共模式 | 前端 | modal、通知、i18n | 新文案双语 |
| `tools/*.yaml` | 命令类能力 | 新安全工具 | 见 `tools/README.md` |

## 4. 高风险区域

| 区域 | 风险原因 | 修改前应检查 |
| :--- | :--- | :--- |
| `internal/security/`（Shell、RBAC） | 可直接执行命令、控制访问 | 权限 Scope、审计、单测 |
| `internal/c2/` | 后渗透与 Beacon | 是否授权、默认关闭、HITL |
| `handler/webshell*.go`、`terminal` | 目标系统远程控制 | 审批、日志、编码边界 |
| `internal/mcp/` 外部 MCP | 第三方进程能力 | 认证、网络隔离、熔断 |
| `tools/` 与 Skills 文件系统工具 | 命令与文件读写 | 角色绑定、白名单 |
| `internal/handler/config.go` | 热应用全局配置 | 旧配置兼容、安全默认值 |
| `internal/multiagent/` 工具注入与摘要 | 影响模型所见上下文 | 回归流式与恢复测试 |

## 5. AI 使用提示

- **需求分析时优先评估影响面**：Handler API、database 迁移、Agent 工具可见性、前端 i18n、OpenAPI、审计/监控
- **实现时优先复用**：YAML 工具 > 新 Go 工具；现有 handler 模式 > 新路由风格；`contributing-guide.md` Checklist
- **应避免直接修改的敏感区域**：未经需求明确的 C2/WebShell 默认策略、全局 HITL 白名单、RBAC 核心判定逻辑
